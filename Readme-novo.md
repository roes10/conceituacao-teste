## Instalar dependências

clonar o projeto e mudar para a branch dev


Entrar na pasta teste


```bash
cd teste/
```


E executar os comandos:
```bash
composer i or composer install
```
```bash
npm i or npm install
```
## Faz a configuração do projeto
```bash
composer setup
```

## Para executar 

>[!TIP] 
> Isso executa o npm run dev e o php artisan serve
```bash
composer run dev
```
